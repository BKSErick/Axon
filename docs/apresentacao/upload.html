📤 Upload de Imagens para Apresentação

Instruções:

  1. Cole sua service_role key do Supabase abaixo
  2. Clique em "Selecionar Imagens"
  3. Selecione TODAS as imagens da pasta d:\MetaAds\docs\apresentacao\
  4. Aguarde o upload completar

Encontre a key em: Supabase → Settings → API → service_role
